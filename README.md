# Proyecto: Carros y Carreras 🏎️

## Pasos para mis compañeros:
1. Clonen este repositorio en su computadora.
2. Abran la terminal en la carpeta del proyecto y corran: 
   `pip install -r requirements.txt` (o `pip3` si usan Mac).
3. **¡MUY IMPORTANTE!** Creen un archivo llamado `.env` en esta misma carpeta y pídanme la URL de la base de datos por privado para que la peguen ahí.
4. Para correr el programa, ejecuten: `python crud.py` (o `python3`).
